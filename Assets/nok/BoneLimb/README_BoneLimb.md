# Bone Rig — แขนขาแบบกระดูก

ท่อนแขน/ขาที่เห็นจะเป็น **กระดูกแข็ง** ติดกับลำตัว แล้วใช้ IK เอื้อมไปหามือ/เท้า
แทนการโชว์ท่อนฟิสิกส์ที่ต่อกันด้วย joint (ซึ่งยืดและแกว่งเหมือนยาง)

**ไม่แตะเกมเพลย์และโค้ดเดิม:** ฟิสิกส์ทุกชิ้น (มือ เท้า ลำตัว joint collider) ยังทำงานเหมือนเดิมบน server
ระบบนี้แค่ซ่อน renderer ของท่อนกลาง แล้ววาดสำเนาบนกระดูกแทน รันเองในทุกเครื่อง ไม่มี RPC
มือ/เท้ายังเป็นชิ้นฟิสิกส์ตัวจริง เพราะเป็นตัวที่ชน ต่อย และจับของ

## เซ็ทอัพ
1. เปิดซีนที่มีหุ่น (เช่น `TestItem`) หรือเปิด prefab `RobotContainer`
2. เลือกหุ่น (`RobotContainer` หรือชิ้นไหนก็ได้ในหุ่น)
3. เมนู **Tools ▸ NSC ▸ Bone Rig ▸ Add To Selected Robot** (ใส่ `RobotBoneRig` ที่ Torso)
4. กด Play

ลบออก: **Tools ▸ NSC ▸ Bone Rig ▸ Remove From Selected Robot**

## ใช้กับโมเดลที่มีกระดูก (เช่น `Assets/nok/robot/newROBOT/RobotNSC_Rigged.fbx`)
1. ทำตามเซ็ทอัพด้านบนก่อน
2. ลากโมเดลไปเป็น **ลูกของ Torso** แล้วจัดตำแหน่ง/ขนาดให้ทับตัวหุ่น (ไหล่/สะโพกของโมเดลตรงข้อต่อของหุ่น)
   - โมเดลนี้แขนสั้นกว่าหุ่นปัจจุบันเกือบ 3 เท่า (ดู Quest Q-20261027-robot-bone-rig) ถ้าไม่ขยาย แขนจะเหยียดตรงไปหามือแต่เอื้อมไม่ถึง
3. ลากโมเดลใส่ช่อง **Rigged Model** ของ `RobotBoneRig`
4. กด Play: กระดูก Mixamo (`LeftArm/LeftForeArm/LeftHand`, `LeftUpLeg/LeftLeg/LeftFoot` และฝั่ง Right) ถูกหาให้เอง
   ถ้าชื่อไม่ตรง ใส่เองในช่อง **Rigged Limbs** (เลือก slot แล้วลากกระดูกจากโคนไปปลาย)

ในโหมดนี้ชิ้นฟิสิกส์ของหุ่นทั้งตัว (ลำตัว หัว แขน ขา มือ เท้า) ถูกซ่อน เหลือแค่โมเดล ส่วนไอเทมที่ถืออยู่ยังเห็นตามปกติ
ชิ้นที่หลุดจะยุบแขน/ขาของโมเดลทิ้ง แล้วโชว์ชิ้นฟิสิกส์ที่หลุดออกไปแทน ส่วนตอนล้มจะซ่อนโมเดลแล้วโชว์หุ่นฟิสิกส์ทั้งตัว

## ค่าใน Inspector (`RobotBoneRig`)
| ช่อง | ใช้ทำอะไร |
|---|---|
| Arms / Legs | เปิดกระดูกให้แขน/ขา แยกกัน |
| Rigged Model / Rigged Limbs | โมเดลที่มีกระดูก (ว่าง = ใช้ mesh เดิมของหุ่น) / กำหนดกระดูกเองถ้าชื่อไม่ใช่ Mixamo |
| Align Hands And Feet | หมุนมือ/เท้าของโมเดลตามชิ้นฟิสิกส์ |
| Pole Mode | `TorsoDirection` = ศอก/เข่าชี้ทิศคงที่เทียบลำตัว (นิ่ง ดูเป็นหุ่น) / `PhysicsJoint` = ตามข้อต่อฟิสิกส์จริง |
| Arm/Leg Pole Direction | ทิศศอก/เข่าในแกนลำตัว ใช้เมื่อโมเดลยืนท่าแขนขาเหยียดตรง (ถ้าโมเดลงออยู่แล้วจะใช้ทิศที่งอนั้น) |
| Physics Look When Ragdoll | ตอนล้มกลับไปโชว์ท่อนฟิสิกส์ ให้ล้มแบบตุ๊กตาเหมือนเดิม |
| Show Physics Parts | โชว์ท่อนฟิสิกส์ซ้อนไว้ด้วย (ไว้ดูว่ากระดูกตามถูกไหม) |

## ทำงานอย่างไร
- ตอนเริ่ม: ไล่ joint จากมือ/เท้าขึ้นไปจนถึงลำตัว → ได้ท่อนบน/ท่อนล่าง
  สร้างกระดูกหนึ่งชิ้นต่อท่อน แล้วสำเนา MeshRenderer ที่มองเห็นอยู่ของท่อนนั้น (ข้ามชิ้นที่ซ่อนอยู่ และชิ้นที่มี Rigidbody ของตัวเอง)
- ทุกเฟรม: ไหล่/สะโพกยึดติดลำตัว ปลายกระดูกไปที่ข้อมือ/ข้อเท้าของชิ้นฟิสิกส์ ความยาวท่อนคงที่
- ชิ้นที่หลุด (`LimbAttachment`) หรือตอนลำตัวล้ม → โชว์ท่อนฟิสิกส์ตามเดิมอัตโนมัติ
