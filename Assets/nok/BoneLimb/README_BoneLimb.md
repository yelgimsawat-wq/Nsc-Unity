# BoneLimb — หุ่นกระดูก + IK

หุ่น `RobotNSC_Rigged` ขยับแขนขาด้วย IK บานพับที่เขียนเอง (`IKLimb.Solve`) ไม่ใช้ระบบหุ่นฟิสิกส์เดิม
ศอก/เข่าพับรอบแกนกระดูกที่โมเดลออกแบบไว้เท่านั้น (ศอก = local Z, เข่า = local X ของโมเดลนี้ หาเองตอนเริ่มใน `DetectHinge`) จึงไม่ทะลุโมเดล
ไม่ใช้ Animation Rigging `TwoBoneIK` แล้ว เพราะมันเลือกระนาบพับเอง ทำให้ปลายแขนบิดผิดแกน (`RigBuilder` ในฉากถูกปิดตอนเริ่ม)
หุ่นตัวเดียว ผู้เล่นคนละชิ้น ใช้หน้าเลือกชิ้นส่วนและระบบห้องเดิมของเกม

## ลองเล่น
เปิด `IKTest.unity` แล้วกด Play → `AutoStartHost` สตาร์ต Host เอง (เหมือนฉาก MAP) → ขึ้นหน้าเลือกชิ้นส่วนเดิม (รูปหุ่น คลิก Left Arm/Right Arm/Left Leg/Right Leg, รายชื่อผู้เล่น) → คลิกชิ้นที่จะคุม → กด **Start**
- ต่อหลายเครื่องด้วย Join code: ผ่านเมนูเกมตามเดิม (AutoStartHost ไม่ทำงานถ้าต่อห้องมาแล้ว)
- ถ้าเจอ "address is already in use" (พอร์ต 7777 ค้างจาก Play รอบก่อนที่ Host ปิดไม่สะอาด) ให้ปิดเปิด Unity ใหม่ ไม่งั้น Netcode จะลบหุ่นในฉาก

## ข้อต่อแบบคน (ปรับได้ใน Inspector หัวข้อ "ข้อต่อแบบคน")
- ไหล่ (ลูกกลม): หัน -50° (ข้ามลำตัว) ถึง 120° (กางไปหลัง), เงย/ก้ม ±80°
- ศอก (บานพับ): งอ 0-140° รอบแกน Z ของกระดูก ศอกชี้ทิศตอน T-pose (ลง-หลัง) หมุนตามการแกว่งของต้นแขนแบบสั้นที่สุด ต่อเนื่องทุกท่า ไม่พลิกขึ้นกลางทาง
- มือ/เท้าไหลตามเคอร์เซอร์แบบนุ่ม (`follow` ใน Inspector) และถ้าเคอร์เซอร์เลยขอบไหล่ แขนติดขอบฝั่งที่อยู่ ไม่กระโดดไปขอบอีกฝั่ง
- ข้อมือ: หันนิ้วไปทางที่แขนเอื้อม (ไหล่ → มือ) หมุนจากท่าตั้งต้นแบบสั้นที่สุด (`OrientHand`) — แขนใช้ rotation ของเป้า (ตั้ง targetRotationWeight = 1 ตอนเริ่ม)
- สะโพก: แกว่งหน้า 70° หลัง 35°, กาง 35° หุบ 15° / เข่า (บานพับ): งอ 0-120° ชี้ไปทางเดียวกับเท้า (ไม่ใช่ทิศลำตัว — เท้าเฉียงแล้วขาไม่บิดที่ข้อเท้า)
- เป้าที่เคอร์เซอร์ชี้ถูกแปลงเป็นมุมข้อต่อแล้วจำกัด (`JointLimit.Limit` = `Angles` → `Direction`, ความยาวจากกฎของโคไซน์) — แขนเท่านั้น: Server ใช้ `Limit` ตัวเดียวกันตรวจเป้าที่ client ส่งมา | ขาเดินแบบหุ่นเดิม: ตัดแค่ระยะ (Server ตรวจไม่เกินความยาวขาจากสะโพก) — เท้าก้าวไขว้/กางได้แบบหุ่นเดิม

## ออนไลน์ทำงานยังไง
- ใครคุมชิ้นไหน = `LimbSelection` ของหน้าเลือกชิ้นส่วนเดิม — หุ่นนี้มี `Robot` + `RobotLimb` 4 ช่อง (`Slot_*`) ให้มันรู้จัก (ไม่มีตัวควบคุมฟิสิกส์ของหุ่นเก่า)
- เครื่องที่จองชิ้นคำนวณเป้าเอง (ไม่หน่วง) แล้วส่ง `SendLimbRpc` → Server ตรวจว่าเป็นเจ้าของ + `Limit` (แขน) / ระยะไม่เกินความยาวขา (ขา) → เขียน `states` → เครื่องอื่น lerp ตาม
- ตัวหุ่นคำนวณบน Server แล้วซิงก์ด้วย NetworkTransform กล่อง `PunchBox` ซิงก์ด้วย NetworkRigidbody
- `IKTest` ต้องอยู่ใน Build Settings (Netcode ใช้ตอนซิงก์ฉาก)

## ล้มออนไลน์ทำงานยังไง
- Server ตัดสินล้ม → `fallen` (NetworkVariable) → ทุกเครื่องเปิด ragdoll; Server จำลองทั้งตัวแล้วประกาศท่าสะโพก client ให้สะโพกตาม ท่อนอื่นห้อยตามข้อต่อเอง (ท่าแขนขาตอนนอนอาจต่างกันเล็กน้อยแต่ละเครื่อง)
- คุมได้ตอนนอน: เป้าแขนขาซิงก์ทาง `SendLimbRpc` เดิม (+ ธง `pull` ใน `LimbNetState`) Server ตรวจแค่ไม่เกินความยาวแขนขาจากโคน ทุกเครื่องออกแรงสปริงดึงท่อนล่างเอง (`IKRagdoll.Pull`, `pullStrength`/`pullDamping`) ตัวหุ่นเคลื่อนจริงตามฟิสิกส์ของ Server; กล้องตอนนอนเลิกมุมแขน ก้มลงมองตัวหุ่นบนพื้น (`OrbitCamera.downPitch/downDistance/downLookHeight`)
- ไม่ลุกเอง: นอนจนทุกคนที่คุมชิ้นของหุ่นตัวนี้กด Q (`StandVoteRpc` → Server นับ; คนที่ออกห้อง/ปล่อยชิ้นไม่ต้องรอ; ไม่มีใครคุมชิ้นเลย = นอนต่อ; เล่นคนเดียว = กด Q ลุกเลย) จอโชว์ `กด Q (n/ทั้งหมด)`
- ลุก: ตัวหุ่นย้ายไปที่สะโพก (NetworkTransform.Teleport), เท้าวางข้างตัว, ไล่ท่ากลับยืน `getUpTime` — ระหว่างนอน/ลุก คุมชิ้นไม่ได้และล้มซ้ำไม่ได้
- กระดูก FBX มีสเกลสะสม ×100 — ขนาด collider ต้องหารด้วย `lossyScale` (ใน `IKRagdoll` ทำให้แล้ว)

## เลือด + ดาเมจ
- เลือด = `LimbHealth` เดิมบน `Slot_*` 4 ช่อง (500, หลุดแล้วเพดานลด 125, ไม่โดนตี 7.5 วิฟื้น 2/วิ, ต่อกลับเต็มตามเพดาน) — เลือดหมด → ชิ้นหลุดเอง (RobotLimb) | ช่อง `Slot_*` ย้ายตามปลายแขนขาทุกเฟรม ให้ศัตรูเล็งชิ้นที่ใกล้ได้ถูก | จอบอกเลือดทุกชิ้น
- ดาเมจหมัด (Server, แบบ `LimbStrike` เดิม): กำปั้นพุ่งออกเร็วกว่า `strikeMinSpeed` 8 m/s แล้วแตะของที่รับดาเมจได้ (`DamageRouter`) = ความเร็วพีค × `strikeSpeedToDamage` 1.6 ไม่เกิน 60, หนึ่งท่าหนึ่งครั้ง — หมัดแตะ ~16-18 m/s ≈ 25-30; ถีบใช้สูตรเดียวกันแต่นับเฉพาะช่วงพุ่งออก (`IKLimb.Kick` ซิงก์ — ก้าวเดิน/ชักเท้ากลับไม่มีดาเมจ) ดาเมจถีบ = ความเร็วพีค × `kickSpeedToDamage` 1.2 (ขาเลือดเต็ม = เพดาน 60, ขาเลือดน้อยเตะเบาลง), source = Kick

## จับ (Half-sword)
ของทดลองในฉาก IKTest: `GrabTest` — โต๊ะนิ่งสูง 9.4 หน้าหุ่น (ของบนโต๊ะอยู่ระดับหมัด ~10 เพราะโหมดต่อสู้กำปั้นลงต่ำไม่ได้ — กล่อง PunchBox สูง 3 มือเอื้อมไม่ถึง) + กล่องเบา (มวล 10) แท่งยาว (25) กล่องหนัก (150) เป็น Rigidbody ธรรมดา (ของที่มี `NetworkRigidbody` ตอน Host เปิดไม่ขึ้นจะถูกล็อก kinematic จับไม่ได้). เดินเข้าไป ~1 ก้าวแล้วต่อยไปที่ของพร้อมเปิดจับ
`IKInput.grab`/`grabPressed` (F) → `IKLimb.Grab` (โหมดกดครั้งเดียวสลับค่าเมื่อกด, ล้ม/ชิ้นหลุด/สลับไปคุมชิ้นอื่น = รีเซ็ตเป็นไม่จับ) (ซิงก์ใน `LimbNetState.grab`) → Server (`ServerGrabs`/`TryGrab`) สร้าง `FixedJoint` บน collider มือ (`_Hit` ที่ตามกำปั้น) ผูกกับ Rigidbody dynamic ที่ใกล้กำปั้นที่สุด, ปิดการชนระหว่างของที่จับกับ collider ตัวหุ่นไว้ (คืนเฉพาะคู่ที่ปิดเอง ไม่ไปแตะคู่ของ `IKDetach`), หมัดไม่นับดาเมจตอนจับ. ปล่อยเมื่อ: ปล่อย F, คนคุมออก, ชิ้นหลุด, ตัวล้ม, ของถูกทำลาย. HUD (Host) โชว์ `<ชิ้น> จับ: <ของ> (มวล)`. ข้อจำกัด: ของต้องซิงก์ผ่านเน็ตเอง (`NetworkObject` + `NetworkRigidbody`) ถึงจะเห็นตรงกันทุกเครื่อง — ของที่ไม่ซิงก์เห็นแค่ Host; ความหน่วงตามน้ำหนักคิดเฉพาะเครื่อง Host (มวลรู้ที่ Server); จับของ kinematic (ปีน) ยังไม่มี

## ยังไม่มี
ศัตรูยังหาเป้าหุ่น IK ไม่เจอ (`EnemyController` ใช้ `robot.Torso` — โค้ดศัตรูอยู่ใน Q-20261028-kaiju-enemy-feel ของ nok), HUD เลือดของเกม (`LocalRobotBinder` ต้องมีตัวควบคุมฟิสิกส์), ตึกพังจากหมัด (`DestructibleBuilding` หา `LimbStrike`), ต่อยตอนนี้แค่ดันของ ไม่มีแรงกระแทก

## ถือของ = โหมดอาวุธ

**ท่าฟันสำเร็จรูป (ค่าเริ่มต้น `weaponFreeAim` ปิด — สำหรับคนเล่นไม่เป็น):** ถือของ → คลิกซ้ายค้าง + ลากเมาส์สั้นๆ (`slashDragPixels` 30px) → เกมเลือกท่าตามทิศที่ลาก แล้วเล่นให้ครบ ง้าง (0.28 วิ) → ฟัน (0.16 วิ เร่งเข้าหาปลาย) → ค้าง (0.2 วิ) → กลับท่าพัก: **ลากลง = ฟันลง** (ยกเหนือหัวแล้วสับ) | **ลากขวา/ซ้าย = กวาดขวา/ซ้าย** | **ลากขึ้น = ฟันขึ้น** (`SlashStep`/`SlashPath`) ความแรงไม่ขึ้นกับความเร็วเมาส์ ท่าเดียวกันดาเมจเท่ากัน | หันเข้าหาศัตรูฝั่งตรงข้ามทีมที่ใกล้สุดด้านหน้า (ในระยะ `slashAssistRange` 3 เท่าแขน หันได้ ±50°) | **ท่าฟันมีพลัง (ตาม `Weapon-Motion-Research.md`):** ง้าง (ศอกงอ รัศมีมือ 0.6) → หยุดที่ยอดแวบหนึ่ง → ฟันเร่งแบบ t³ ศอกเหยียดช่วงท้าย (0.97) → เลยเป้า 12% แล้วเด้งกลับ → ค้าง แล้วกลับท่าพัก | ลำตัวนำแขน: บิด/เอนตามทิศที่มือกำลังจะไป (นำ ~0.1 วิ × ความหนัก) + ตัวพุ่งตอนฟาดเร็ว | ใบตั้ง ~90° กับแขนตอนช้า/ง้าง ต่อแนวแขนตอนฟาดเร็ว | **มือจับ:** ด้ามพาดเฉียงในอุ้งมือ 38° (`GripDiagonal` — ใบเอียงไปทางนิ้ว เหมือนคนจับดาบ) + ข้อมือจำกัดตามมือคน (`wristLimits`: เอียงนิ้วก้อย 20° / นิ้วโป้ง 10° / งอ 40° / แอ่น 35°) และมุมรวม `weaponWristBend` 35° ทุกกรณี (รวมตอนบิดหน้าไม้) — ผ่านผู้ตรวจมือ 3 รอบ — ตอนฟาดเร็วใบทำมุม ~25° กับแขน ไม่ต่อแนวแขนตรงแบบชี้นิ้ว | **ท่าพัก Pflug:** ด้ามหน้าสะโพก ศอกงอ ใบชี้ขึ้นหน้า ~45° | ต่อคอมโบหลังเลยเป้าแล้วเด้ง (เห็นแขนเหยียดสุดก่อน) | **ความหนัก:** `slashWeight` (ค่าเริ่มต้น 2 = หุ่นพันตัน) คูณเวลาง้าง/ฟัน/ค้าง และหารความเร็วแขนตามเป้า — 1 = ไวแบบเดิม | **ของติดมือ:** ถืออยู่ = ของเป็น kinematic ตามท่าเทียบมือที่เก็บตอนจับ (`PlaceHeld`: FixedUpdate MovePosition ดันของอื่นได้ + LateUpdate ตั้งท่าตรงๆ ภาพตรงมือทุกเฟรม) ปล่อย = กลับเป็นฟิสิกส์ พุ่งต่อด้วยความเร็วตอนปล่อย — ของที่ถือทะลุผนัง/พื้นนิ่งได้ (ไม่ถูกดันออก) | **คอมโบปุ่มเดียว:** คลิกซ้ายเฉยๆ (ไม่ลาก) = กวาดขวา → กวาดซ้าย → ฟันลง วนไป (เว้นเกิน 1.2 วิ เริ่มใหม่) | **จอย:** X/□ หรือ R1 = คอมโบ, ดีดสติ๊กขวา = ทิศฟัน | **บอกว่ากดติด:** ลูกศรทิศฟันใหญ่กลางล่างจอทันทีที่รับคำสั่ง (จาง 0.5 วิ) + ลูกศรเล็กข้างๆ = ท่าที่จองต่อไว้ | | **ฟาดต่อ/ฟาดกลับ:** ลากอีกครั้งตั้งแต่ช่วงฟัน = จองท่าถัดไป เริ่มทันทีที่ฟันถึงปลาย ง้างสั้นตามระยะที่ต้องไป (0.08–0.28 วิ — กวาดขวาแล้วกวาดซ้ายแทบไม่ต้องง้าง) | **บิดหน้าไม้:** หน้าไม้ (ฝั่งสันหมัด) หันไปทางที่ฟาดเอง ฟาดกลับ = ข้อมือบิดพลิกหน้าไม้ (`AimWeapon` ทุกเครื่องคิดจากเป้ามือที่ซิงก์) | **มือกำ:** ด้ามวางที่กลางวงที่นิ้วกลางโอบตอนกำ (`IKLimb.BakeGrip`) นิ้วงอรอบด้าม | เปิด `weaponFreeAim` = กลับไปโหมดลากเมาส์คุมแขนอิสระ (ด้านล่าง)

- จับอะไรอยู่ (F) แขนข้างนั้นเลิกตั้งการ์ด/ชาร์จหมัด (`DriveWeaponArm`): **ปล่อยเมาส์ = แขนห้อยตรงข้างตัว กางพ้นขา ปลายอาวุธชี้ลงหน้า ~37° เฉียงออกนอกขา** (ท่าพักแบบลูกเสือถือไม้) | **คลิกซ้ายค้าง + ลากเมาส์ = หมุนแขนรอบไหล่ไปทางที่ลาก** (ใช้แค่ระยะลาก ไม่ใช่ตำแหน่งเคอร์เซอร์ — ลากขึ้น = ยกขึ้นเหนือหัว, ลากลง = สับลง, ซ้าย/ขวา = กวาด; `weaponSwingPerPixel` 0.18°/พิกเซล — แขนห้อยอยู่ ลากขึ้น = ยกไปข้างหน้า) แขนเหยียด 0.92 ตามเป้าเป็นวงโค้งรอบไหล่ (ไม่ตัดเข้าหาไหล่ตอนฟาดเร็ว) ลากเร็ว = ฟาดเร็ว ของหนักตามช้าลง (`GrabLag`) | ปลายอาวุธ (`AimWeapon` ทุกเครื่องคิดเอง): ห้อย = ชี้ลงหน้า, ยกแขน = ชี้ไปทางเดียวกับแขน — บิดข้อมือรอบแนวแขนก่อน แล้วงอไม่เกิน `weaponWristBend` 90° | ลำตัวตามมือ (`WeaponPose`): มือไปหลัง/ข้าง = บิดง้างสุด `weaponTwist` 40°, สับลงหน้า = โน้มหน้า `weaponLean` 18°, เหนือหัว = เอนหลังครึ่งหนึ่ง (ท่าพักไม่บิด) | รอยแสงที่ปลายของตอนปลายเร็วเกิน 3 เท่าเกณฑ์ต่อย (`weaponTrail` = `WeaponTrail.mat`, ทุกเครื่องสร้างเอง) | ปล่อย F = กลับตั้งการ์ด
- ดาเมจ: Server วัดความเร็ว **ปลายของ** (ด้านไกลจากมือ) ตอนเร็วเกิน `strikeMinSpeed` ฟาดทางไหนก็นับ ชนอะไรตลอดลำ (มือ → ปลาย) = ดาเมจตามความเร็วพีค × `strikeSpeedToDamage` (เพดาน `strikeMaxDamage`) แหล่ง `MeleeWeapon` ผ่าน `DamageRouter` | หนึ่งท่าหนึ่งดาเมจเหมือนหมัด
- นิ้วกำรอบของ: แต่ละข้อนิ้วงอจากโคนไปปลาย ข้อไหนแตะผิวของในมือ (`IKLimb.Holding` ทุกเครื่องหาเองจากกลางกำปั้น) หยุดตรงนั้น — ด้ามบางกำแน่น ด้ามหนากำได้แค่โอบ | ด้ามวางหน้าฝ่ามือ (เลื่อนจากกลางกำปั้นออกทางฝ่ามือ = ครึ่งความหนาด้าม + เนื้อฝ่ามือ)

## จุดจับ (GripPoint)

**ไม่ต้องวางก็ได้:** กล่องยาว (BoxCollider ยาว ≥ 2.5 เท่าด้านอื่น เช่นไม้ ดาบ) ที่ไม่มี `GripPoint` ระบบสร้างให้เองตอนเอื้อม/หยิบ ที่ปลายฝั่งใกล้มือ (15% จากปลาย) แกน X ตามความยาว (`GripPointOf`) — วางเองเมื่ออยากกำหนดจุด/ท่าถือเฉพาะ | รอยแสงไม่ได้ตั้งใน Inspector = ใช้ `Resources/WeaponTrail.mat`
 — กำหนดว่าของชิ้นไหนถือตรงไหน ท่าไหน

1. เลือกของที่หยิบได้ (มี Rigidbody) → คลิกขวา ▸ Create Empty ให้เป็น **ลูกตรงของ GameObject ที่มี Rigidbody** → ตั้งชื่อ `GripPoint` (ตัวสะกดตรงนี้ ระบบหาจากชื่อ)
2. ลากไปวางตรงที่อยากให้มือกำ (เช่น ปลายด้ามไม้) — ระบบเอาจุดนี้ไว้กลางกำปั้น
3. หมุนให้แกนตรงกับมือ (กด Local ที่ปุ่มบนซ้ายของ Scene view เพื่อดูแกนของจุดนั้น):
   - **X แดง = แนวด้าม** (ทิศที่ด้ามทะลุกำปั้น)
   - **Z น้ำเงิน = ทิศที่พ้นปลายแขนออกไป** (ข้อมือ → นิ้ว)
   - **Y เขียว = ทางฝ่ามือ**

4. เซฟฉาก/Prefab แล้ว Play: ชี้ของ (เรือง) → F → แขนเอื้อมไปที่จุดจับเอง จับแล้วของหมุนเข้ามือตามแกนที่วาง
