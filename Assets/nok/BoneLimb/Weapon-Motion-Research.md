# หุ่นยักษ์ใช้อาวุธ: สรุปวิจัย + สิ่งที่ต้องแก้ (2026-10-29)

รวมจากทีมค้นหา 3 ทีม (Sonnet): ของก้อนใหญ่ / ดาบ / เทคนิคให้ท่ามีพลัง — ตัดหมวดอาวุธอื่นออกแล้ว (ผู้ใช้ 2026-10-29: ไม่จำเป็นตอนนี้)
**ความน่าเชื่อถือ:** ข้อมูลที่อ่านจริงส่วนใหญ่มาจาก biomechanics มนุษย์ (hammer throw, sledgehammer, kendo, HEMA longsword) + หลักแอนิเมชัน 12 ข้อ + บทความ game feel — ข้อมูลเฉพาะหุ่นยักษ์ในหนัง/เกม (Pacific Rim, Gundam ฯลฯ) หาอ่านได้น้อยมาก ตัวเลขเวลา/มุมส่วนใหญ่เป็น **ค่าเริ่มต้นสำหรับจูน** ไม่ใช่ค่ามาตรฐาน

## 1. ข้อสรุปที่ทั้ง 3 ทีมตรงกัน

1. **แรงมาจากล่างขึ้นบน (kinetic chain):** ขา/สะโพก → ลำตัว → ไหล่ → ศอก → ข้อมือ → อาวุธ แต่ละส่วนเริ่มช้ากว่าส่วนก่อน ~50–150 ms ถ้าแขนขยับก่อนหรือพร้อมลำตัว = ท่าดูอ่อน
2. **จังหวะ ช้า–เร็ว–ช้า:** ง้าง : ฟัน : ฟื้นตัว ≈ **3 : 1 : 2.5** (ของหนักมาก ≈ 1 : 0.25 : 1.2) + **หยุดนิ่งที่ยอด 80–150 ms** ก่อนฟาด ช่วงฟันต้อง **เร่งเข้าหาปลาย** (ease t² – t³) ความเร็วสูงสุดตอนถึงเป้า ไม่ใช่ตอนต้น
3. **ศอกงอตอนง้าง แล้วค่อยเหยียดตอนท้าย** (70–90% ของช่วงฟัน) — แขนเหยียดตรงตลอด = สาเหตุอันดับ 1 ของ "แข็ง"
4. **อาวุธตามหลังมือ (wrist lag) 20–40°** แล้วสะบัดตามทันตอนท้าย + **เลยเป้า 5–10° แล้วเด้งกลับ** (spring)
5. **ตัวเอนเข้าหาการฟัน 10–20°** ย่อเข่า 15–30° สะโพกลดลง 3–10% ตอนกระทบ แขนอีกข้างเหวี่ยงสวน 20–30%
6. **ตอนกระทบ:** hit-stop 80–160 ms (หยุดเฉพาะแขน/อาวุธ/เป้า ไม่หยุดทั้งเกม) + กล้องสั่นแบบ trauma² 1.5–3° 250–450 ms + ฝุ่นพื้น + เสียงหลายชั้น (วูบ → ต่ำ → เหล็ก → เศษ)
7. **อาวุธใหญ่ใช้สองมือเป็นหลัก** — *พักไว้ก่อน (ผู้ใช้ 2026-10-29): อาจมีได้ แต่ต้องดูระบบให้ดี*
8. **คอมโบ:** ท่าจบของท่าหนึ่ง = ท่าง้างของท่าถัดไป ไม่กลับท่าการ์ดระหว่างท่า

## 2. ท่าการ์ด / ท่าวางแขนก่อนโจมตี (ดาบ)

- **ท่าพัก (Pflug):** ด้ามที่สะโพก/สะดือ ใบชี้ไปข้างหน้า-ขึ้น 40–50° ศอกแนบซี่โครง
- **ท่าพร้อมฟัน (Vom Tag):** ด้ามข้างไหล่ระดับคาง ศอกงอ 90–110° ใบเอียงไปหลัง 45–60° เหนือไหล่ — ฟันลงได้แรงที่สุด อ่านง่ายเป็นเงา
- เปลี่ยนท่าพัก ↔ พร้อมฟันใน 0.6–0.8 วิ ยืนเท้ากว้าง 1.2–1.5 เท่า ย่อเข่า เท้าข้างมือดาบนำนิดหน่อย มีโยกหายใจเบาๆ ไม่นิ่งสนิท

## 3. การจับ

- ด้ามพาดเฉียงในอุ้งมือ ใบออกทางนิ้วโป้ง **ตอนพักใบทำมุม ~90° กับแขน ข้อมือเอียง 10–20°**
- **ตอนกระทบเท่านั้น** ที่ข้อมือตรงและใบเกือบต่อแนวแขน
- จับแปลกเมื่อ: ใบต่อแนวแขนตลอดเหมือนชี้นิ้ว / มือสองข้างห่างกันมาก / ด้ามอยู่ที่ปลายนิ้ว / ข้อมือตรงล็อกตอนพัก
- *(พักไว้ — จับสองมือ)* สองมือ: มือหลังชิดปลายด้าม มือหน้าห่าง ~1 ความกว้างมือ มือหลังออกแรง มือหน้าบังคับทิศ — มือรองใช้ IK วางบนด้ามจริง ไม่ลอยตามมือหลัก
- กำแน่นขึ้นแวบเดียวตอนกระทบ (นิ้วบีบ 2–4 เฟรม) แล้วคลาย

## 4. ท่าโจมตี (ค่าเริ่มต้นสำหรับจูน)

| ท่า | ง้าง | ฟัน | ตามท่า / จบ |
|---|---|---|---|
| **ฟันลง** | ใบเลยแนวตั้งไปหลัง 100–120° ลำตัวเอนหลัง 10–15° ยกไหล่ สะโพกลด 3–4% | ก้าวเท้าหน้า สะโพกนำ ลำตัวก้มหน้า 20–30° ศอกเหยียดช้า (ได้แรงสะบัด) | ใบเลยลงถึงระดับเข่า มือจบต่ำ → **เป็นท่าง้างของฟันขึ้น** |
| **กวาดข้าง** | บิดลำตัว 45–70° หนีทิศฟัน ดาบอยู่ข้าง/หลังสะโพก มือระดับเข็มขัด | สะโพกหมุน 30–50° ก่อน แล้วไหล่ตาม (+~120 ms) ใบตามหลังมือ 20–40° | เลยเป้า 30–45° ลำตัวรวมบิด 70–90° → **กลับทิศเป็นกวาดกลับ (เลข 8)** |
| **ฟันขึ้น** | ใบต่ำชี้หลัง ย่อ 5–8% ลำตัวก้ม 10° | ดันขาขึ้น ตวัดข้างตัว กระทบ 30–45° เหนือแนวนอน | จบสูงเหนือไหล่ = **ท่าพร้อมฟันลง** (ฟันลง → ขึ้น → ลง วนได้) |

เวลา (หุ่นยักษ์ ~1.5–3 เท่าของคน): ง้าง 0.7–0.9 วิ / ฟัน 0.25–0.35 วิ / ฟื้นตัว 0.6–0.8 วิ — คอมโบรับคำสั่งช่วง 40% ท้ายของการฟื้นตัว ท่าต่อเนื่องลดเวลาง้าง 30–40%

## 5. ของก้อนใหญ่ (ไม่ใช่อาวุธ)

- **เลือกมือ:** ของยาวกว่า ~ครึ่งความสูงหุ่น หรือหนักจนจุดศูนย์ถ่วงอยู่ห่างตัวเกินหนึ่งช่วงแขน → **บังคับสองมือ**
- **ท่าถือ:** กอดหน้าอก (ของกว้าง/หนัก — ศอกอยู่ใต้ของ ตัวเอนหลัง 5–15° ถ่วงน้ำหนัก) / พาดบ่า (ของยาว — เสา คาน) / ลาก (หนักเกินยก — ตัวเอนหน้า ก้าวสั้น ของครูดพื้นตามหลัง)
- **ยกจากพื้น:** ย่อเข่า งอสะโพก หลังตรง ของอยู่ใต้กลางเท้า ยกด้วยขาก่อน แขนตามทีหลัง
- **ฟาดด้วยของหนัก:** วงจากต่ำขึ้นสูง ยืดสุดที่ยอดแล้วหยุดโหลดแวบหนึ่ง เร่งช้าๆ แล้วระเบิดแรงครั้งเดียวตอนท้าย ฟื้นตัวนานกว่าช่วงฟันหลายเท่า ผู้เล่นรอได้ก่อนท่าต่อไป
- **ปล่อย = วาง** (ความเร็วเกือบ 0 ตัวถอยนิดหน่อย มีฝุ่น/สะเทือนตอนตกถึงพื้น) ต่างจาก **ขว้าง** (ใช้ลำดับเดียวกับการฟาด ปล่อยมือตอนท้าย มุม ~40° ตัวหุ่นเซตามแรง)

## 6. เทียบกับของเรา (ก่อนแก้ 2026-10-29) (ปัญหาที่ผู้ใช้เห็น)

| ผู้ใช้เห็น | สาเหตุในของเรา (เทียบกับข้อสรุปข้างบน) |
|---|---|
| **ท่าแข็งแต่ไม่แรง** | แขนเหยียด 0.95 ตลอดท่าฟัน (ไม่มีงอ→เหยียด) / ลำตัวบิด **ตาม** มือ ไม่ใช่ **นำ** มือ / ช่วงฟัน 0.32 วิ ยาวกว่าคำแนะนำ ไม่มีหยุดที่ยอด ไม่มีเลยเป้า / ยังไม่มี hit-stop กล้องสั่น ฝุ่น เสียง |
| **ท่าจับแปลก** | ตอนยกแขน เราหันใบให้ต่อแนวแขนตลอด (= "ชี้นิ้ว" ที่วิจัยบอกว่าแปลก) — ควร ~90° ตอนพัก/ง้าง ต่อแนวแขนเฉพาะตอนกระทบ / มือเดียวตลอด |
| **ท่าวางแขนก่อนโจมตี** | แขนเหยียด ใบชี้ขึ้น-หน้า มือเดียว — ควรเป็น Pflug (ด้ามที่สะโพก ศอกงอ) ตอนพัก และ Vom Tag ตอนพร้อมฟัน |
| **ท่าโจมตี 3 แบบ** | เป็นแค่การหมุนแขนจากจุด A ไปจุด B บนทรงกลม — ไม่มีขั้นลำตัว/ขา ไม่มีงอศอก จบแล้วไม่ต่อเป็นท่าง้างของท่าถัดไป |
| ของหนักรู้สึกเบา (ข้อ 9) | น้ำหนักทำแค่แขนช้าลง — ไม่มีตัวเอนถ่วง ย่อเข่า ถ่างขา |
| ของทะลุผนัง (ข้อ 10) | ระหว่างถือ ของตามมือตรงๆ ไม่ถูกผนังดัน |
| ของไม่ยาวถือไม่สวย (ข้อ 12) | ของใหญ่ไม่มีท่ากอด/พาดบ่า/สองมือ |

## 7. ลำดับแก้ที่แนะนำ (ถูก → แพง) — ทำแล้ว 1–5 (2026-10-29)

1. **จังหวะใหม่:** ง้าง ~0.8 วิ → หยุดที่ยอด 0.12 วิ → ฟัน 0.25 วิ เร่งแบบ t³ → เลยเป้า + เด้งกลับ → ฟื้นตัว 0.7 วิ
2. **งอศอกตอนง้าง เหยียดตอนท้ายฟัน** (รัศมี 0.6 → 0.97)
3. **ลำตัวนำแขน:** บิด/เอน/ย่อตามช่วงของท่าฟัน (นำแขน ~100 ms) + แขนอีกข้างเหวี่ยงสวน
4. **มุมใบ:** ~90–110° กับแขนตอนพัก/ง้าง → ต่อแนวแขนตอนกระทบ + ใบตามหลังมือ 20–40°
5. **ท่าพัก Pflug / ท่าพร้อม Vom Tag** แทนท่าแขนเหยียด
6. **ตอนกระทบ:** hit-stop + กล้องสั่น + ฝุ่น (ต้องเทสดาเมจได้ก่อน — port 7777)
7. ~~**สองมือ:** มือรองจับด้ามจริงด้วย IK~~ — พักไว้ (ผู้ใช้: ต้องดูระบบให้ดีก่อน)
8. **ของใหญ่:** ตัวเอนถ่วงตามน้ำหนัก + ท่ากอด/พาดบ่า + บังคับสองมือ (ข้อ 9, 12) / ของที่ถือชนผนังแล้วหยุด (ข้อ 10)
