# คู่มือระบบ PVP — หุ่นแดง vs หุ่นน้ำเงิน

สคริปต์ PVP ทั้งหมดอยู่ใน `Assets/nok/PVP/`
มีไฟล์นอกโฟลเดอร์ที่ถูกแก้ **1 ไฟล์** คือ `OnlineNetworkUI.cs` (กด Host แล้วเลือกขนาดห้อง 4/8 คน)

---

## 1. ระบบนี้คืออะไร

เกมนี้ผู้เล่น 1 คน = **ชิ้นส่วน 1 ชิ้นของหุ่น** (แขนซ้าย/ขวา, ขาซ้าย/ขวา)
โหมด PVP คือ **หุ่นแดง 1 ตัว ปะทะ หุ่นน้ำเงิน 1 ตัว** ทีมละไม่เกิน 4 คน = ห้องละ 8 คน

```
        ทีมแดง (4 คน)                    ทีมน้ำเงิน (4 คน)
        ┌─────────────────┐              ┌─────────────────┐
        │   หุ่นแดง       │  ⚔️  ต่อย ⚔️  │   หุ่นน้ำเงิน   │
        │ แขนซ้าย  ●      │ ───────────► │ แขนซ้าย  ●      │
        │ แขนขวา   ●      │              │ แขนขวา   ✕ หลุด │
        │ ขาซ้าย   ●      │              │ ขาซ้าย   ●      │
        │ ขาขวา    ●      │              │ ขาขวา    ✕ หลุด │
        └─────────────────┘              └─────────────────┘
```

**เงื่อนไขชนะ: ทำให้ชิ้นส่วนของหุ่นอีกทีมหลุดครบทั้ง 4 ชิ้นก่อน**

### ⚠️ PVP ไม่มีระบบเลือดของตัวเอง

ใช้ **`RobotHealth` เดิม** ที่มีอยู่แล้วทั้งหมด — เลือดอยู่ที่ **ชิ้นส่วน** ไม่ใช่ที่หุ่นทั้งตัว

| | ค่า |
|---|---|
| เลือดต่อชิ้นส่วน | 500 |
| เลือดหมด | ชิ้นส่วนหลุดออกจากหุ่น |
| ทุกครั้งที่หลุด | เพดานเลือดชิ้นนั้นลดถาวร −125 (ต่ำสุด 50) → ต่อกลับมาก็เปราะกว่าเดิม |

ผลที่ตามมา: **PlayerHUD เดิม (วงแหวนเลือด + การ์ดสถานะแขนขา) ทำงานเองอัตโนมัติ** ไม่ต้องต่ออะไรเพิ่ม

### ⚠️ วงแหวน HULL เดิมโชว์แค่ชิ้นที่คุณถือ

`HullRingUI` ออกแบบมาให้โชว์เลือดของ **"ชิ้นส่วนที่ผู้เล่นคนนี้คุม"** ชิ้นเดียว
โดนต่อยที่ลำตัวหรือแขนอีกข้าง วงแหวนจึง **ไม่ขยับ** → รู้สึกเหมือน "ต่อยแล้วเลือดไม่ลด" ทั้งที่ดาเมจเข้าแล้ว

**ยังไม่มีหลอดเลือดของฝั่งตรงข้าม** ตามที่ตกลงไว้ — ต้องดูสภาพหุ่นศัตรูจากในเกมว่าแขนขาหลุดไปกี่ชิ้น

## 2. ติดตั้ง

### ขั้นที่ 1 — เตรียมฉาก

สร้างฉากใหม่ `Assets/nok/scene/PVP.unity` แล้ววาง:

| ต้องมี | หมายเหตุ |
|---|---|
| **หุ่น 2 ตัว** | ก็อปหุ่นเดิมเป็นตัวที่สอง วางห่างกัน ~10-15 เมตร หันหน้าเข้าหากัน |
| **NetworkManager** | ตั้ง Player Prefab เหมือนฉากเกมปกติ |
| **พื้น + NavMesh** | ตามปกติ |

> ⚠️ **ห้ามมี `LobbyManager` ในฉากนี้** — มันมีระบบ `DisableExtraRobots` ที่จะปิดหุ่นตัวเกินทิ้ง เหลือหุ่นตัวเดียวแล้วสู้กันไม่ได้

> 💡 commit งานค้างก่อนรันขั้นถัดไป เพราะเมนูจะไปแก้ไฟล์ฉากของคุณ

### ขั้นที่ 2 — ติดตั้งหุ่น

```
Tools ▸ NSC ▸ PVP ▸ Setup Robots In Scene
```

- แปะ `PvpRobotTeam` บนลำตัวหุ่นแต่ละตัว (เรียงตามชื่อ: ตัวแรก = **แดง**, ตัวที่สอง = **น้ำเงิน**)
- แปะ `PvpDamageSender` ให้ทุกมือและทุกเท้า
- สร้าง `PvpTeamManager` พร้อม `NetworkObject`
- เตือนถ้าหุ่นไม่มี `RobotHealth` สักชิ้น (ต่อยแล้วเลือดจะไม่ลด)

### ขั้นที่ 3 — สร้าง UI

```
Tools ▸ NSC ▸ PVP ▸ Build PVP UI
```

- หน้าจอเลือกทีม (ปุ่ม RED/BLUE + รายชื่อ + ปุ่มเลือกชิ้นส่วน + ปุ่ม START)
- หน้าจอจบแมตช์ VICTORY/DEFEAT + ปุ่ม EXIT TO MENU และ REMATCH (ดูหัวข้อ "หน้าจอจบแมตช์")
- วาง `PlayerHUD.prefab` เดิมลงฉากให้ พร้อมแปะ `PvpPlayerHudGate` (ซ่อน HUD ระหว่างเลือกทีม)

### ขั้นที่ 4 — สร้างแผงเลือกขนาดห้อง (ทำครั้งเดียว ที่ฉากเมนู)

เปิดฉากเมนู (ตัวที่มี `OnlineNetworkUI`) แล้วสั่ง:

```
Tools ▸ NSC ▸ PVP ▸ Build Room Size Panel
```

สร้างแผงพร้อมต่อสายให้เสร็จ — กด Host ในเกมจะได้หน้าตาแบบนี้:

```
              ┌─────────────────────────────────┐
              │           ROOM SIZE             │
              │  เลือกขนาดห้อง เปลี่ยนทีหลังไม่ได้  │
              │  ┌───────────┐ ┌───────────┐   │
              │  │ 4 PLAYERS │ │ 8 PLAYERS │   │
              │  │   Co-op   │ │    PVP    │   │
              │  └───────────┘ └───────────┘   │
              │           [ CANCEL ]            │
              └─────────────────────────────────┘
```

จากนั้นตั้งค่าใน Inspector หมวด **PVP Mode**:

| ช่อง | ใส่อะไร |
|---|---|
| `Pvp Scene Name` | ชื่อฉาก PVP ของคุณ (เช่น `PVP`) |
| `Max Players Pvp` | `8` |

แล้วเพิ่มฉาก PVP เข้า **Build Settings**

> ถ้าไม่รันเมนูนี้ ปุ่ม Host จะทำงานแบบเดิม (สร้างห้อง 4 คนเลย) ไม่พัง

### เช็คลิสต์ก่อนกด Play

- [ ] ลำตัวหุ่นทั้งสองตัวมี `NetworkObject`
- [ ] ทุกแขน/ขามี `RobotHealth` (ระบบเลือดเดิม)
- [ ] `PvpTeamManager` มี `NetworkObject` และ `redRobotRoot`/`blueRobotRoot` ไม่ว่าง
- [ ] ในฉากไม่มี `LobbyManager`
- [ ] ฉาก PVP อยู่ใน Build Settings

## 3. เข้าเล่นยังไง

**Host**
1. เมนูหลัก → Online → **Host** → เลือก **8 PLAYERS (PVP)**
2. ได้ room code → ส่งให้เพื่อน
3. รอครบ → กด **Start** → เข้าฉาก PVP เลย (ไม่ต้องเลือกแมพ เพราะเลือกโหมดไปตั้งแต่ตอนสร้างห้องแล้ว)

**เพื่อน**
1. Online → **Join** → พิมพ์ code → รอ Host กด Start

**ในฉาก PVP**
1. หน้าจอเลือกทีมเด้งขึ้นเอง → กด **RED** หรือ **BLUE** (ทีมเต็ม 4 คนแล้วกดไม่ได้)
2. กดเลือกชิ้นส่วน (ชิ้นที่เพื่อนจองแล้วจะกดไม่ได้ / กดชิ้นเดิมซ้ำ = ยกเลิก)
3. Host กด **START FIGHT** → ถ้ากดไม่ได้ให้อ่านข้อความบนปุ่ม มันบอกเหตุผลอยู่
4. ต่อยกันจนชิ้นส่วนอีกฝั่งหลุดครบ 4 ชิ้น

> **ทำไมต้องเลือกขนาดห้องก่อนสร้าง?**
> ความจุห้องถูกล็อกตอน `CreateSessionAsync` ซึ่งเกิดก่อนเลือกแมพ และเปลี่ยนทีหลังไม่ได้
> ถ้าไม่รู้โหมดตั้งแต่ตอนสร้างห้อง ก็ตั้งความจุ 8 เฉพาะ PVP ไม่ได้

## 5. ปรับความยาก

### `PvpDamageSender` (บนมือ/เท้าทุกชิ้น)

| ช่อง | ความหมาย | ค่าเริ่มต้น |
|---|---|---|
| `speedToDamage` | ตัวคูณความเร็วหมัด → ดาเมจ | 0.6 |
| `forceToDamage` | ตัวคูณแรงปะทะ → ดาเมจ (ใช้กับเท้า) | 0.01 |
| `minVelocityThreshold` | ความเร็วขั้นต่ำที่นับดาเมจ | 8 |
| `maxDamagePerHit` | เพดานดาเมจต่อครั้ง | 60 |
| `limbDamageMultiplier` | ตัวคูณตอนต่อยเข้าแขน/ขาตรงๆ | 1.0 |
| `bodyDamageMultiplier` | ตัวคูณตอนต่อยเข้าลำตัว (ลงชิ้นใกล้จุดปะทะสุด) | 1.0 |
| `friendlyFire` | เปิด = ตีเพื่อนร่วมทีมเข้า | ปิด |

**คำนวณจำนวนหมัด:**
```
หมัดเต็มแรง ~55 m/s × 0.6 = ดาเมจ 33 ต่อหมัด
ชิ้นส่วนเลือด 500 ÷ 33  ≈  15 หมัด ต่อ 1 ชิ้น (ถ้าต่อยเข้าชิ้นเดียวตรงๆ)
```

> ⚠️ **ห้ามตั้ง `speedToDamage` สูงพลการ** — `RobotHealth.ServerTakeDamage` เอาดาเมจไป
> **คูณ 2 เป็นแรงกระเด็น** (`AddForce(direction * amount * 2f, Impulse)`)
> ตั้ง 1.2 แล้วดาเมจ 66 จะกลายเป็นแรงกระแทก 132 → หุ่นปลิว
> ค่า 0.6 คือค่าเดียวกับที่เกมใช้ตอนตีบอส ปลอดภัยแล้ว

- อยากให้สู้นานขึ้น → เพิ่ม `MaxHp` ที่ `RobotHealth`
- อยากให้จบไว → ลด `limbsLostToLose` (เช่น 2 ชิ้นก็แพ้)
- อยากให้เล็งแขนคุ้มกว่าตีลำตัว → ลด `bodyDamageMultiplier` (เช่น 0.6)

### `PvpRobotTeam` (บนลำตัวหุ่น)

| ช่อง | ความหมาย | ค่าเริ่มต้น |
|---|---|---|
| `team` | หุ่นตัวนี้ทีมไหน | Red / Blue |
| `limbsLostToLose` | ชิ้นส่วนหลุดกี่ชิ้นถึงแพ้ | 4 |
| `defeatCheckInterval` | ความถี่เช็คว่าหลุดครบยัง (วิ) | 0.25 |

### `PvpTeamManager`

| ช่อง | ความหมาย |
|---|---|
| `maxPlayersPerTeam` | คนสูงสุดต่อทีม (1-4) |
| `requireBothTeams` | ปิดถ้าอยากเทสคนเดียว |
| `requireLimbSelection` | ปิดถ้าอยากเริ่มได้แม้ยังไม่มีคนจองชิ้นส่วน |

**เทสคนเดียว:** ปิด `requireBothTeams` + `requireLimbSelection` → Play เป็น Host → เลือกทีมแดง จองแขน กด START → ต่อยหุ่นน้ำเงินที่ยืนนิ่ง ดูว่าเลือดในวงแหวน HUD ของมันลดไหม

## 6. ระบบทำงานยังไง

### การเลือกทีม
วิ่งผ่าน `NetworkList<PvpPlayerEntry>` ที่ **server เขียนคนเดียว**
```
Client กดปุ่ม → RequestTeamRpc → Server ตรวจ (ทีมเต็มไหม/แมตช์เริ่มยัง)
              → เขียนลง NetworkList → ทุกเครื่อง refresh UI พร้อมกัน
```

### การนับดาเมจ
`PvpDamageSender.OnCollisionEnter` — **รันเฉพาะบน Server**

1. ต้องอยู่ในสถานะ `Fighting` เท่านั้น
2. `PvpRobotTeam.FindByPart(collider)` ไล่ขึ้น parent จนรู้ว่า collider นี้เป็นของหุ่นตัวไหน
3. เป็นหุ่นตัวเอง / ทีมเดียวกัน / แพ้ไปแล้ว → ไม่นับ
4. หา `RobotHealth` ของชิ้นส่วนที่โดนตี แล้วเรียก `ServerTakeDamage()` → **เข้าระบบเดิมทั้งหมด**
   - **ถ้าโดนลำตัว** (ไม่มี `RobotHealth` เพราะไม่มี joint ให้หลุด) → `ServerApplyBodyDamage()`
     โยนดาเมจเต็มจำนวนให้ชิ้นส่วนที่ **ใกล้จุดปะทะที่สุด** ชิ้นเดียว
     (ไม่นับดาเมจเลยเกมจะรู้สึกพัง เพราะผู้เล่นย่อมเล็งลำตัวซึ่งเป็นเป้าใหญ่สุด)

   > ⚠️ **ห้ามหารกระจายให้ทุกชิ้นเท่าๆ กัน** — ทุกชิ้นเลือด 500 เท่ากัน ถ้าโดนเท่ากันทุกหมัด
   > มันจะถึง 0 พร้อมกันเป๊ะ แล้ว **หลุดหมดทั้ง 4 ชิ้นพร้อมกัน** = หมัดเดียวจบเกม
   > (เคยทำแบบนี้แล้วพัง จึงเปลี่ยนมาเป็นชิ้นใกล้สุดชิ้นเดียว)
5. `NotifyPunchImpact()` → หนึ่งหมัด = หนึ่งดาเมจ ไม่นับซ้ำจากการครูด

### การตัดสินแพ้ชนะ
`PvpRobotTeam` เช็คทุก 0.25 วิ (บน server) ว่า `JointPullAndReconnect.IsConnected` ของชิ้นส่วนที่ cache ไว้ยังต่ออยู่กี่ชิ้น — หลุดครบตามเกณฑ์ → `PvpTeamManager.ServerReportDefeat()`

> cache รายชื่อชิ้นส่วนตั้งแต่ตอน spawn ไม่ไล่หาใหม่ เพราะชิ้นที่หลุดแล้วอาจถูกย้าย parent ออกนอกหุ่น ถ้าไล่หาใหม่จะ "หาไม่เจอ" แทนที่จะเห็นว่ามันหลุด

### หน้าจอจบแมตช์
`PvpResultUI` ฟัง `OnWinnerDecided` แล้วเทียบ `LocalTeam` กับผู้ชนะ — ทีมเราชนะขึ้น **VICTORY** ทีมเราแพ้ขึ้น **DEFEAT** (คนที่ไม่ได้เลือกทีมขึ้น MATCH OVER)

| ปุ่ม | ใครกดได้ | ทำอะไร |
|---|---|---|
| `EXIT TO MENU` | ทุกคน | `ReturnToMenuOnHostLost.LeaveMatchAsync()` — ออกเฉพาะเครื่องตัวเอง (ตัวเดียวกับปุ่ม LEAVE MATCH ในเมนูระหว่างเล่น) |
| `REMATCH` | Host | โหลดซีนเดิมซ้ำผ่าน NGO ทุกเครื่องตามมาพร้อมกัน ทุกระบบรีเซ็ตเอง |

> ปุ่มออกให้ **ทุกคน** กดได้ ต่างจากโหมดบอสที่ให้เฉพาะ Host — เพราะ PVP ฝั่งที่แพ้ต้องออกได้เองทันที
> ไม่ต้องนั่งรอ Host ส่วน Host กดออก = ห้องสลาย คนอื่นถูก `ReturnToMenuOnHostLost` เด้งกลับเมนูตามเอง

> ตอน panel ขึ้นจะตั้ง `GameFlowManager.GameEnded = true` (flag กลางที่มือ/เท้าเช็ค) + `UiFocus.Push`
> เพื่อกันสคริปต์ผู้เล่นแย่งล็อกเมาส์กลับ ไม่งั้นเมาส์จะหายทันทีที่คลิกและกดปุ่มไม่ได้

### ทำไม `PvpRobotTeam` อยู่บนลำตัว ไม่ใช่ root
root ของหุ่นในโปรเจกต์นี้**ไม่มี** `NetworkObject` (แต่ละ limb มีของตัวเองแยกกัน) แต่ `NetworkVariable` ต้องอยู่บน `NetworkBehaviour` ที่มี `NetworkObject` → ลำตัวจึงเหมาะที่สุด

### ทำไมไม่ใช้ `transform.root` เทียบหุ่น
ถ้าเอาหุ่นสองตัวไปไว้ใต้ parent เดียวกัน ทั้งคู่จะได้ root เดียวกัน → แยกทีมไม่ออก → ตีกันไม่เข้าเลยสักหมัด จึงใช้วิธีไต่หา ancestor ที่สูงสุดเท่าที่ยังครอบ **ลำตัวเดียว** อยู่แทน

## 7. แก้ปัญหา

| อาการ | สาเหตุ / วิธีแก้ |
|---|---|
| ต่อยแล้วเลือดไม่ลด | ยังไม่ได้กด START — ดาเมจนับเฉพาะตอน `Fighting` |
| กด START แล้วยังไม่ลด | ชิ้นที่โดนตี**ไม่มี `RobotHealth`** — PVP ยิงดาเมจเข้าระบบเดิม ถ้าไม่มีก็ไม่มีอะไรให้ลด |
| ตีลำตัวแล้วเลือดไม่ลด | ต้องรัน `Setup Robots In Scene` ใหม่ — ตอนนี้ต่อยลำตัวได้แล้ว ดาเมจกระจายลงชิ้นส่วน |
| ต่อยโดนแต่วงแหวน HULL ของคนโดนไม่ขยับ | ปกติ — วงแหวนโชว์แค่ชิ้นที่เขาถือ ดูจากสภาพหุ่นในเกม หรือ Console |
| ต่อยทีเดียวแขนขาหลุดหมดพร้อมกัน | เวอร์ชันเก่าหารดาเมจให้ทุกชิ้นเท่ากัน → ถึง 0 พร้อมกัน แก้แล้ว ให้อัปเดตโค้ด |
| อยากรู้ว่าดาเมจเข้าจริงไหม | ดู Console ฝั่ง Host หา `[PVP] 🥊 ... เลือด 500 → 475` |
| Console เตือน "หา PvpRobotTeam ไม่เจอ" | `robotRoot` ชี้ผิดตัว หรือลำตัวไม่ได้อยู่ใต้ root นั้น |
| ชิ้นหลุดครบแล้วแต่ไม่จบแมตช์ | `limbsLostToLose` ตั้งไว้มากกว่าจำนวนชิ้นที่หาเจอ — ดู log ตอน spawn ว่าเจอกี่ชิ้น |
| หุ่นเหลือตัวเดียว | มี `LobbyManager` ในฉาก → ลบออก |
| Setup บอก "เจอหุ่น 1 ตัว" | หุ่นสองตัวอยู่ใต้ parent เดียวกัน หรือตัวที่สอง inactive |
| HUD โผล่ทับหน้าจอเลือกทีม | ไม่มี `PvpPlayerHudGate` บน PlayerHUD → รัน Build PVP UI ใหม่ |
| ห้องจอยได้แค่ 4 คน | ตอนกด Host เลือก 4 PLAYERS ไป ต้องเลือก **8 PLAYERS (PVP)** |
| กด Host แล้วสร้างห้องเลย ไม่มีให้เลือก | ยังไม่ได้รัน **Build Room Size Panel** ที่ฉากเมนู |
| Client เห็น "Players: 2/4" ในห้อง PVP | `Max Players Pvp` ยังไม่ได้ตั้งเป็น 8 |
| กด START ไม่ได้ | อ่านข้อความบนปุ่ม มันบอกเหตุผลอยู่ |
| UI ไม่ขึ้นเลย | ไม่มี `EventSystem` ในฉาก |
