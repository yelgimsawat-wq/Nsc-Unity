## ฟีล Pacific Rim

**กฎเหนือทุกข้อ:** นำเสนอให้ยิ่งใหญ่จริงจังแบบหนัง แต่ "การบังคับยังเงอะงะเหมือนเดิม" — ดนตรีฮีโร่ + สโลว์โมชัน + หุ่นสะดุดล้มใส่ตึก คือความตัดกันที่ทำให้เกิดคลิป อย่าแก้จนบังคับง่ายแล้วความฮาหาย

1. **ขนาดและน้ำหนัก (สำคัญที่สุด)**
   - กล้องต่ำ มองเงย ตามตัวหน่วงนิดหน่อย ทุกก้าวจอสั่น ฝุ่นฟุ้ง รถเด้ง — ต่อที่ `PlayerCam` + Cinemachine Impulse
   - หมัดต้องมีท่าง้างแล้วชาร์จแบบเดียวกับเตะ (ตอนนี้มือพุ่ง 60 m/s ไวเกินจะดูยักษ์) และสโลว์แวบเดียวตอนเข้าเป้า
   - เสียง: เหล็กกระทบตึง ไฮดรอลิกฟู่ เบสหนักตอนเท้ากระแทก; ของรอบตัว (รถ คน เฮลิคอปเตอร์) ต้องดูเล็ก
2. **นักบินซิงก์กัน ("ลิงก์ประสาท")**
   - เกจซิงก์กลางจอ เช่น "NEURAL SYNC 87%" เติมจากท่าซิงก์ ซิงก์ต่ำ = หุ่นอืด ซิงก์สูง = ปลดอาวุธหนัก
   - ฟิลเตอร์วิทยุบนไมค์ (`VoiceChat` / UniVoice) — "แขนซ้ายหลุด!" ผ่านวิทยุ
   - HUD โฮโลแกรมห้องนักบิน แจ้งเตือน "LEFT ARM — OFFLINE" ไฟแดงกะพริบ — ต่อยอด `HullRingUI`, `LimbStatusUI`
3. **ไคจูและสนามรบ**
   - บอสเป็นสัตว์ประหลาดโผล่จากทะเล (แทนแพนด้า) คำรามและเรืองแสงก่อนโจมตีทุกครั้ง
   - ฉาก: กลางคืน ฝนตก นีออนสะท้อนพื้นเปียก ไซเรน; ด่านท่าเรือที่หุ่นยืนน้ำลึกระดับเข่า
   - อาวุธระดับหุ่นยักษ์: หมัดจรวดจากศอก ดาบโซ่ ปืนพลาสมา ยกตู้คอนเทนเนอร์/เรือฟาด — คนคุมแขนเลือกอาวุธของแขนตัวเอง
   - แขนโดนฉีกต้องเป็นฉากใหญ่: ประกายไฟ เสียงเตือน สโลว์โมชัน (ระบบหลุด/ดึงกลับมีอยู่แล้ว)
4. **พิธีก่อนออกรบ** — ล็อบบี้เลือกแขนขาเป็นโรงเก็บหุ่นที่นักบิน 4 คนเดินเข้าประจำที่; เฮลิคอปเตอร์หย่อนหุ่นลงเมือง ~10 วิ กดข้ามได้
5. **ลิขสิทธิ์ (ถ้าจะขาย)** — ห้ามใช้ชื่อหรือดีไซน์ของหนัง: Jaeger, Drift, Shatterdome, Gipsy Danger, เลือดสีฟ้าแบบในหนัง ให้ตั้งคำของเราเอง (เช่น "ลิงก์ประสาท") คำว่า "ไคจู" ใช้ได้

**เริ่มก่อน (งานเล็ก ฟีลเปลี่ยนเยอะ):** กล้องสั่น + ฝุ่น + เสียงเหล็กทุกก้าว · MAPBOSS เป็นกลางคืนฝนตก · ฟิลเตอร์วิทยุบนไมค์ · เสียงเตือน ARM OFFLINE ตอนชิ้นหลุด — ทำแล้วอัดคลิปเทียบกับก่อนทำ

## ก่อนลงแรงหนัก ต้องพิสูจน์ 3 เรื่อง

1. **เล่นข้ามเน็ตจริงครบ 4 คน** — ฟิสิกส์คำนวณที่ server ทั้งหมด client จะรู้สึกหน่วงตาม ping ถ้ารับไม่ได้ต้องรื้อโมเดลเน็ตเวิร์ก (ความเสี่ยงใหญ่สุด)
2. **ฟีลยักษ์** — ปรับกล้อง หมัดชาร์จ เสียงก้าวเท้า แล้วดูว่าฟิสิกส์ตอนนี้ให้ความหนักได้ไหม (คาดว่าได้ด้วยการปรับค่า)
3. **เล่น 1–2 คนได้** — ให้หนึ่งคนคุมหลายชิ้น และชิ้นที่ไม่มีคนคุมมี AI ช่วยทรงตัว

## ยังเป็นไอเดีย (ต้องถามผู้ใช้ก่อนทำ)

### ทางไปขายบน Steam
- รูปแบบเกม co-op แนวเดียวกับ Lethal Company / R.E.P.O. / PEAK: **หุ่นรับจ้าง** — รับงานในเมือง (รื้อตึก ส่งของห้ามแตก กู้ภัย ไล่ไคจู) → ได้เงิน → อัปเกรดแขนขาของตัวเอง → งานยากขึ้น → ไคจูปิดท้าย
- ต้องมีตามลำดับความสำคัญ: เล่นได้ 1–4 คน, ชวนเพื่อนผ่าน Steam (ไม่ใช่โค้ดห้อง), คลิปง่าย (ปุ่มเซฟ 10 วิ), หน้าตาที่จำได้ (ไม่ใช่เมืองจาก asset store ล้วน), ภาษาอังกฤษก่อน, ความเสถียรและรองรับจอย; PVP เป็นโหมดเสริม
- การตลาด: ทดสอบคลิปสั้นก่อนสร้างเยอะ → เปิดหน้า Steam เก็บ wishlist เร็ว → เดโมใน Steam Next Fest + ส่งสตรีมเมอร์ → ราคาประมาณ $7–10
- ไม่ทำ: เนื้อเรื่องยาว, โลกเปิด, PVP แข่งจริงจัง

### ไอเดียความสนุก (สรุปจากแคนวาส)
- **ตัวฆ่าความสนุกที่เจอจากเทสต์ 2026-10-09:** บอสตีโดนนอกรัศมี (`guaranteeHitInReach` ตีติดที่ 17–20 ม. ทั้งที่รัศมี 8 ม.), เริ่มเกมหุ่นนอนกองต้องกด Q โดยไม่มีป้ายบอก, ต่อย/เตะวืดเพราะไม่รู้ระยะเอื้อม, แขนหลุดไปฝังในตึกดึงกลับไม่ได้, ปัญหาข้อมูลฉาก Parkour/PVP (ดู [Status.md](Status.md))
- **Juice:** hit-stop 40–90 ms, กล้องสั่นตามแรง, เอฟเฟกต์ปะทะ 3 ระดับ (ช่อง impactVfx/Sfx ใน `LimbStrike` ยังว่าง), ชิ้นหลุดเป็นฉากใหญ่, บอสบอกก่อนตี, เป้าเล็งบอกระยะ, คอมโบของทั้งหุ่น, เสียงประกาศ
- **ท่าซิงก์** (ต่อยอด `coopJumpWindow` 0.3 วิใน `TorsoBalance`): Double Impact (สองแขนต่อยพร้อมกัน), Rocket Stomp, ของหนักต้องสองมือแล้วขว้าง, เดินสลับเป็นจังหวะ = วิ่ง, ช่วยเพื่อนต่อแขน, Overdrive ร่วมของทั้งหุ่น — หน้าต่างซิงก์ควร 0.25–0.35 วิ เพราะเน็ตมีดีเลย์
- **โหมด:** Boss 3 เฟส + บอสขโมยแขน + จุดอ่อนที่หลัง; Parkour มี ghost + ช่วงเฉพาะแขน/ขา + น้ำไล่ขึ้น; PVP ซูโม่บนดาดฟ้า + ฉีกแขนศัตรูเป็นกระบอง; โหมดใหม่ ส่งของห้ามแตก / รื้อเมือง 2 นาที / สลับร่างทุก [45] วิ
- **สังคม:** รางวัลหลังเกม (หมัดเหล็ก, ตัวถ่วงแห่งแมตช์, ฮีโร่ต่อแขน, นักซิงก์), รีเพลย์ 10 วิสุดท้าย, แต่งแขนขาของตัวเอง, วงล้อสั่งการเร็ว, สอนเล่น 60 วิด้วย "ลุกขึ้นพร้อมกัน"
- **ลำดับที่แนะนำ:** Sprint 1 แก้ตัวฆ่าความสนุก + Juice → Sprint 2 ท่าซิงก์ + รางวัลหลังเกม → Sprint 3 เนื้อหาใหญ่ (บอสใหม่ ยกของ Overdrive โหมดใหม่)
