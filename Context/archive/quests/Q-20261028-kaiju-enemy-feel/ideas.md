# ไอเดีย GameFeel ไคจู — สำหรับ Q-20261028-kaiju-enemy-feel

เป้าหมายเดียว: **ผู้เล่นต้องรู้สึกว่ากำลังสู้กับสิ่งมีชีวิตยักษ์ ที่หนัก ช้า แต่ตีทีเดียวโลกสั่น**
ความรู้สึก "ยักษ์" ไม่ได้มาจากขนาดโมเดลอย่างเดียว แต่มาจาก **จังหวะ (ช้าก่อน-แรงทีเดียว)** และ **โลกรอบตัวที่ตอบสนอง**

## ขั้นต่ำ 5 อย่าง (ทำก่อน ได้ฟีลเยอะที่สุดต่อแรงที่ลง)

1. **ก้าวเท้า = เหตุการณ์** — ทุกครั้งที่เท้าไคจูแตะพื้น: จอสั่น + ฝุ่น + เสียงทุ้ม
   ใช้ของที่มีแล้ว: `Nsc.Feel.ImpactFeel.PlayFootstep(ตำแหน่ง, แรง 0..1)` (ทำทั้งสามอย่างให้เลย ค่าจูนใน `Assets/_Game/Resources/FeelConfig.asset`)
   จับจังหวะเท้าแตะพื้นได้จาก Animation Event ในคลิปเดิน หรือเช็กกระดูกเท้าต่ำกว่าพื้น
2. **บอกก่อนตีเสมอ (anticipation)** — ง้างช้าๆ 0.8–1.5 วิ ให้เห็นชัด แล้วตีเร็ว 0.1–0.2 วิ
   ระหว่างง้าง: ตา/ปาก/หลังเรืองแสง, คำราม, ยกตัวสูงขึ้น, ฝุ่นร่วงจากตัว
   ความต่าง "ง้างนาน-ตีไว" นี่แหละที่ทำให้ดูหนักและน่ากลัว (ตีไวตลอด = ดูเป็นตัวเล็ก)
3. **หนักตอนเปลี่ยนทิศ** — หันตัวไม่เกิน ~30–45°/วิ, ออกตัว/หยุดมีแรงเฉื่อย (ไหลเลยนิดแล้วกลับ)
   หัวหันไปมองผู้เล่นก่อน ตัวค่อยหันตาม (หัวนำ ตัวตาม = มีชีวิต)
4. **กระแทกแล้วโลกพัง** — ท่าตบ/กระทืบพื้น: คลื่นกระแทก (วงฝุ่น/รอยร้าวแผ่ออก), ของรอบๆ กระเด็น, หุ่นที่อยู่ใกล้เสียหลัก
   หยุดภาพแวบหนึ่งตอนโดนหุ่น: `Nsc.Feel.ImpactFeel.PlayHit(จุด, ทิศผิว, ดาเมจ)` (มีหยุดภาพ + จอสั่น + ประกายไฟ + ซูมแวบ)
5. **โดนตีแล้วมีปฏิกิริยา** — หมัดหนักเข้า: สะดุ้งหัว/ไหล่ (ไม่ต้องหยุดเดิน), เซถอย 1 ก้าวถ้าโดนหนักติดกัน, คำรามโกรธ
   ไคจูที่ไม่สะดุ้งเลย = รู้สึกเหมือนตีกำแพง ไม่สนุก

## เพิ่มเติม

**เสียงคำราม** — pitch ต่ำ ยาว มีเสียงก้อง ใช้ก่อนเข้าเฟสใหม่/ก่อนท่าใหญ่: ยืดตัว เงยหน้า จอสั่นเบาๆ ยาวๆ (`CameraShake.Add`) ไปพร้อมเสียง
