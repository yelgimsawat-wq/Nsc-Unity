# Q-20261030-sword-360-slash — บันทึกรับช่วง

## ผู้ใช้ขออะไร (ตามลำดับ)
1. ฟันดาบที่ "ควบคุมง่าย ท่าสวย มีอิสระ" → ตกลงทำแบบผสม: ลากเลือกแนว 360° + ระบบสร้างวงฟันให้ (คล้าย Mordhau)
2. กังวลมือบิดไม่เป็นธรรมชาติ → ทำตัวกันมือบิด + เครื่องมือวัดทุกมุม
3. "ดาบอยู่ไหน" → วางดาบที่หยิบได้ใน TestItem (`WeaponRack`)
4. หลังลองเอง: ข้อมือพลิกบางจังหวะ, บางท่าควรยืดแขนได้มากกว่านี้, **เส้นที่วาดควรคุมปลายดาบ ไม่ใช่มือ** (เดิมดาบตั้งขึ้น ฟันไม่ถึงศัตรู), อยากให้ใบดาบเรียงตามเส้น
5. ส่งภาพ: ข้อมือหงายพลิกตอนง้าง
6. "บางทีมือพลิกกระทันหัน" แล้ว "ดาบยังกระตุก" ← **งานค้างอยู่ตรงนี้**

## สร้างอะไรไปแล้ว (ทั้งหมดใน `RobotIKControl.cs` เว้นแต่ระบุ)
| ส่วน | ที่อยู่ในโค้ด | ทำอะไร |
|---|---|---|
| วงฟัน 360° | `SlashLine`, `KindAngle`, `SlashPath` | มุมไหนก็ได้ → ต้น/ปลายวงฟัน ไล่จากท่าต้นแบบ 4 ทิศ (มุมตรงท่าเดิม = ท่าเดิมเป๊ะ) + เลื่อนตามจุดเล็ง + ชาร์จง้างลึก |
| อินพุต | `ReadSlashInput`, `IssueSlash`, `StartSlash`, `CursorAim`, `AimHit` | ชี้→กดค้าง+ลาก (≥ `slashDragPixels`)→ปล่อย = ฟัน, ลากต่อระหว่างง้าง = ปรับมุม, ลากระหว่างฟัน = จองท่าถัดไป, คลิกเฉยๆ = คอมโบเดิม, จอยดีดสติ๊ก = 4 ทิศเดิม |
| ชาร์จ | `SlashStep` (`slashHold`, `slashCharge`) | ค้างที่ยอดง้าง ชาร์จเต็มใน `slashChargeTime`×slashWeight: ง้างลึก +15% ฟันไว +30% (ดาเมจคิดจากความเร็วปลายดาบอยู่แล้ว ไม่ต้องแก้ server) |
| มุมห้าม | `ComfortAngle`, `slashBlockedArc` (45±15° แขนขวา, แขนซ้ายกระจก) | ฟันย้อนขึ้นข้ามลำตัว ลากเข้า = ปัดไปขอบ |
| ปลายดาบตามเส้น | `AimBlade` → `slashBlade`/`slashTangent`, `BladeLength`; `AimWeapon` ใช้ `slashBlade` เป็น `want` | ง้าง = ใบเอนไปหลังตามเส้น, ฟัน = สะบัดออกจนใบยื่นตามแนวไหล่→มือ, ปลายวิ่งบนเส้นที่ระยะ แขน+ดาบ |
| แขนยืด | `ElbowCocked` 0.7, `ElbowExtended` 0.98, strike ใช้ `Sqrt(k)` | เหยียดตั้งแต่ต้นวงฟัน |
| เส้นนำ | `DrawGuide` (LineRenderer, `slashPreview`) + `DrawSlashCue` (ลูกศรหมุนตามมุม) | วาดที่ระยะปลายดาบ เห็นเฉพาะคนคุม |
| หน้าดาบ | `AimWeapon` สาขา `slashTangent != 0` | ดาบสองคม: เลือกคมฝั่งใกล้, หมุนได้ไม่เกิน `SlashEdgeTurn` 30° (ตอนท่าไม่ใช่ 360°: latch + `edgeRollFollow`) |
| คว่ำ/หงายมือ | `LimitForearmRoll`, `forearmRollLimit` 90 | ศูนย์ = ท่าจับมือ (นิ้วโป้งชี้ทางต้นแขน วัดจากไหล่/ศอก/ข้อมือทุกเฟรม), เกินเพดานค้างฝั่งเดิม (hysteresis), นุ่ม `ForearmRollSmoothing` 12 + เพดาน `ForearmRollSpeed` 720°/วิ |
| กันกระตุกขั้นสุดท้าย | ท้าย `AimWeapon` (`lastHandRot`, `HandTurnSmoothing` 25, `HandTurnSpeed` 1400) | ท่ามือสุดท้ายไล่แบบนุ่ม หมุนไม่เกินเพดาน — **เพิ่งใส่ ยังไม่ได้วัดผล** |
| เครื่องตรวจ | `logSlashWrist`, `LogSlashWrist`, `DebugSlashSweep` (#if UNITY_EDITOR) | log ช่วงมุมของทุกท่า / ใส่ของใส่มือแล้วไล่ฟันทุก step° |
| อื่นๆ | `Closest()` | แทน `Collider.ClosestPoint` ทุกจุด — MeshCollider ไม่ convex ใช้ bounds (เดิม Unity เตือนเหลืองทุกครั้ง) |

## ผลวัดที่ได้ (2026-10-30, Play mode เล่นคนเดียว, แขนขวา, ดาบ Sword_R ยาว 5 มวล 25)
- ยืนถือนิ่ง: คว่ำ/หงาย -11° (ใกล้ท่าจับมือ = จุดอ้างอิงถูก), ดาบไม่สั่นเลย (0°/เฟรม)
- ไม่จำกัด (โค้ดเดิม): ฟันลง -30..15° ปกติ, **ฟันขึ้นมือหงายพลิกถึง ±177°** (ตรงภาพผู้ใช้), กวาดข้าง 100–147°
- จำกัด ±90 แบบตรงๆ: ค่าข้าม ±180 ทำให้จำกัดแล้วกระโดด +90 → -90 ในเฟรมเดียว (= "พลิกกระทันหัน") → แก้ด้วย hysteresis
- หน้าดาบเดิม (หันคมตามทิศมือ): หมุนรอบตัวเองรวม ~350° ต่อการฟัน → ตอนนี้ 98–191°
- ก่อนใส่ `HandTurn*`: ความเร็วดาบสูงสุดต่อท่า 1161°/วิ (ฟันลง) แต่ 6000–12800°/วิ (ฟันขึ้น/กวาดข้าง) = บางเฟรมกระโดด 60–119° ที่ ~100fps
- ภาพหยุดเฟรม: ง้างฟันลง ดาบยกเหนือหัว, กลางวงฟันลงดาบยื่นไปหน้า, กวาดข้างดาบยื่นออกตามแนวกวาด, ง้างฟันขึ้นกำปั้นตั้งปกติ (หลังจำกัด)

## ต้นเหตุที่เหลือ (ถ้ายังกระตุกหลังวัดรอบหน้า)
- จังหวะใบเกือบขนานแนวแขน (ตอนฟันผ่านเป้า ใบ = แนวไหล่→มือ): `ProjectOnPlane(want, along)` ใน `AimWeapon` เหลือแทบศูนย์ → มุมหมุนรอบแนวแขน (`SignedAngle(a, b, along)`) ไม่นิ่ง และ `FromToRotation` ทิศใกล้ 180° แกนไม่นิ่ง — `HandTurn*` ใส่ไว้เป็นตาข่ายกันไว้ก่อน ถ้ายังไม่พอให้ข้ามการหมุนรอบแนวแขนเมื่อ `b.sqrMagnitude` เล็ก (ใช้ค่าเฟรมก่อน)
- `AimBlade` เปลี่ยนช่วง (ง้าง→ยอด→ฟัน→เลยเป้า) ใช้ Slerp คนละสูตร ความเร็วทิศใบไม่ต่อเนื่องที่รอยต่อ
- ขีดจำกัดข้อมือ (`ClampWrist`, `weaponWristBend` 35°) หมุนมือหลังจากจำกัดคว่ำ/หงาย อาจดันมุมกลับเล็กน้อย

## วิธีวัด (Unity MCP `execute_code`)
1. ห้ามกด Play ระหว่าง Unity คอมไพล์ (`EditorApplication.isCompiling`) — เคยทำแล้ว Unity รีโหลดกลาง Play ragdoll เป็น null (`IKRagdoll.Enforce` NullReference ทุกเฟรม) ท่าฟันค้าง ดูเหมือนบั๊กแต่ไม่ใช่
2. ก่อน Play ปิด `AutoStartHost` ในหน่วยความจำ (`FindAnyObjectByType<AutoStartHost>().enabled = false`) ให้เป็นเล่นคนเดียว แล้วเปิดคืนหลังเทส **อย่าเซฟซีน** (TestItem มีงานผู้ใช้ที่ยังไม่เซฟค้างอยู่ — อย่าโหลดซีนทับด้วย)
3. ใน Play: ตั้ง `selected`=1, `limb.Grab`=true, ย้าย Sword_R ไปที่ `limb.GripCenter`, ตั้ง `grabWant[1]`=ดาบ (ห้ามตั้งถ้าถืออยู่แล้ว — ค้างแล้ว `DriveWeaponArm` ไม่ทำงาน) แล้วเรียก `StartSlash(1, limb, มุม, Vector2.zero, false)` ผ่าน reflection หรือ `StartCoroutine(DebugSlashSweep(1, ดาบ, 30f))`
4. วัด `Quaternion.Angle` ของดาบเฟรมต่อเฟรม ÷ `Time.deltaTime` — เป้า: ไม่มีเฟรมเกิน ~2000°/วิ
5. ถ้าหน้าต่าง Game ไม่มีโฟกัสบางครั้ง Input หยุด — คลิก Game view ก่อน
